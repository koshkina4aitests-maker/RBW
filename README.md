# RBW — Автоматизированное рабочее место руководителя

Система включает:

- современный светлый веб-интерфейс руководителя;
- управление задачами сотрудников;
- дашборды и аналитическую отчетность;
- визуализацию документа и процесс подписания;
- backend API с PostgreSQL и синтетическими данными по отчетности подчиненных.

## Стек

### Frontend

- React + TypeScript
- Vite
- CSS (адаптивный UI)

### Backend

- Node.js + Express
- PostgreSQL (`pg`)

## Запуск проекта

### 1) Запуск backend

```bash
cd server
npm install
cp .env.example .env
```

В конфиге `.env` уже проставлен IP `85.209.0.78`.
При необходимости проверьте ключевые параметры:

- `HOST=85.209.0.78`
- `DATABASE_URL=postgres://postgres:postgres@85.209.0.78:5432/rbw`
- `CORS_ORIGIN=http://85.209.0.78:5173`

Запуск:

```bash
npm run dev
```

При старте сервер автоматически:

- создает таблицы отчетности и документов (если их нет);
- заполняет их синтетическими данными (если таблицы пустые).

Отдельный скрипт для загрузки синтетических данных в БД:

```bash
npm run load-synthetic-data
```

### 2) Запуск frontend

В новом терминале:

```bash
cd app
npm install
cp .env.example .env
npm run dev
```

В конфиге frontend также явно проставлен IP `85.209.0.78`:

- `VITE_API_BASE_URL=http://85.209.0.78:4000/api`
- `VITE_DEV_HOST=85.209.0.78`

## Что реализовано

1. **Постановка задач сотрудникам**
   - создание задач;
   - контроль статусов и прогресса;
   - фильтрация по статусам.

2. **Дашборд отчетности подчиненных из PostgreSQL**
   - синтетические данные по месяцам;
   - переключение вида: **за месяц / накопительно**;
   - выбор месяца;
   - график и таблица по сотрудникам.

3. **Аналитическая отчетность**
   - динамика назначения и выполнения;
   - сводные KPI;
   - таблица с месячными и накопительными показателями.

4. **Документы и подписание**
   - визуализация содержимого документа;
   - отображение статуса согласования/подписания;
   - подписание документа электронной подписью (симуляция) через API;
   - реестр документов.

5. **Уведомления**
   - панель уведомлений;
   - pop-up для действий руководителя с переходом к целевому экрану.
