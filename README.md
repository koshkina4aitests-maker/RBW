# RBW — Автоматизированное рабочее место руководителя

Современное светлое веб-приложение для руководителя с фокусом на:

- постановку задач сотрудникам;
- контроль выполнения задач;
- дашборды по типам задач;
- аналитическую отчетность;
- уведомления о действиях (согласование/подписание) с pop-up переходом.

## Стек

- React + TypeScript
- Vite
- CSS (адаптивный светлый UI)

## Запуск

```bash
cd app
npm install
npm run dev
```

Откройте локальный адрес из вывода Vite в браузере.

## Основные разделы интерфейса

1. **Постановка задач**
   - форма создания задачи;
   - выбор исполнителя, типа, приоритета и срока;
   - контроль статуса и прогресса по каждой задаче.

2. **Дашборды**
   - выполнение задач по типам;
   - распределение по статусам;
   - загрузка сотрудников.

3. **Аналитическая отчетность**
   - динамика созданных/выполненных задач;
   - ключевые метрики периода;
   - табличная детализация по месяцам.

4. **Уведомления**
   - панель уведомлений;
   - непрочитанные события;
   - pop-up для срочных действий руководителя с переходом к нужному разделу.
