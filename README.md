# RBW — АРМ руководителя (демо)

В репозитории находится демо-прототип **автоматизированного рабочего места руководителя**:

- постановка задач сотрудникам
- дашборды по выполнению задач (по типам)
- аналитическая отчетность
- уведомления о необходимости действий (согласование/подписание)

Проект — Next.js (TypeScript) и находится в папке `rbw/`.

## Запуск локально

```bash
cd rbw
npm install
npm run dev
```

Открыть в браузере `http://localhost:3000`.

## Данные

Данные хранятся в локальном JSON-файле `rbw/data/rbw.json` (создаётся автоматически при первом запуске).
